## 🃏 הפרויקט המתמשך – כרטיס ביקור

ארבעת השיעורים הראשונים בונים **את אותו דף** – וכל שיעור מוסיף לו שכבה:

1. **HTML** – התוכן: תמונה, שם, תפקיד, כישורים וקישורים.
2. **CSS** – העיצוב: כרטיס לבן וממורכז, תמונה עגולה, כישורים כ"גלולות".
3. **JavaScript** – ההתנהגות: כפתור לייק שסופר לחיצות, ומצב כהה.
4. **נתונים** – כל הפרטים עוברים לאובייקט ב-JavaScript, והרשימה נבנית מתוך מערך.

שיעורים 5 ו-6 בונים שתי אפליקציות קטנות – **קטלוג קורסים** ו**רשימת משימות** – בשיטה שעליה בנויה React: הנתונים במקום אחד, ופונקציה אחת (`render`) שמציירת מהם את המסך. בחלק של React נבנה אותן שוב – ונראה כמה קוד נעלם.

## 🛠️ מה צריך כדי להתחיל

- מחשב עם **Google Chrome**.
- **VS Code** – בחינם, מ-[code.visualstudio.com](https://code.visualstudio.com).

זהו. את **Node.js** נתקין בשיעור 7, כשמתחילים את React.

> 💡 **פרויקטי React (שיעור 7 ואילך)** נשמרים **בלי** התיקייה `node_modules`. כדי להריץ אחד מהם: פותחים את תיקיית `project` ב-VS Code, ובטרמינל – `npm install` ואז `npm run dev`.
