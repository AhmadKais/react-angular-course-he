## תרגיל 1 ⭐ – החיבור הראשון

1. צרו תיקייה `ex1` ובה `index.html` עם שלד מלא, כותרת `h1` ושלוש פסקאות.
2. צרו `style.css` וחברו אותו לדף.
3. כתבו כללים כך ש:
   - הרקע של כל הדף יהיה צהוב-בהיר (`lightyellow`).
   - הכותרת תהיה בצבע `darkgreen`, בגודל `40px` וממורכזת.
   - כל הפסקאות יהיו בגופן `Arial, sans-serif` ובגודל `18px`.

## תרגיל 2 ⭐ – מצאו את הבאגים

ב-CSS הבא יש **חמש** טעויות, ולכן חלק מהעיצוב לא עובד. מצאו ותקנו את כולן, וכתבו ליד כל תיקון הערה (`/* ... */`) שמסבירה מה היה לא בסדר.

```css
body {
  background-color: #f1f5f9
  font-family: Arial, sans-serif;
}

card {
  background-color: white;
  padding: 20 px;
}

h1 {
  colour: navy;
  font-size: 32;
}
```

וה-HTML שמשתמש בו:

```html
<div class="card">
  <h1>Hello</h1>
</div>
```

## תרגיל 3 ⭐⭐ – שלוש הודעות

צרו דף עם שלוש פסקאות, כל אחת עם מחלקה אחרת: `success`, `warning`, `error`.

```html
<p class="success">Your file was saved.</p>
<p class="warning">Your battery is low.</p>
<p class="error">Wrong password!</p>
```

עצבו כל אחת כ"קופסת הודעה":

- לכולן: `padding` של `15px`, פינות מעוגלות של `8px`, ו-`margin` של `10px` בין אחת לשנייה.
- `success` – רקע ירוק בהיר, טקסט ירוק כהה.
- `warning` – רקע צהוב בהיר, טקסט כתום כהה.
- `error` – רקע אדום בהיר, טקסט אדום כהה, **ומסגרת** אדומה של `2px`.

**שאלה למחשבה:** כתבתם את אותם `padding`, `border-radius` ו-`margin` שלוש פעמים? נסו להוסיף לכל הפסקאות מחלקה **שנייה** משותפת: `class="message success"` (שתי מחלקות מופרדות ברווח), ולשים את מה שמשותף בכלל אחד של `.message`.

## תרגיל 4 ⭐⭐ – מודל הקופסה

צרו `div` עם המחלקה `box` ובתוכו המילה `Box`. עצבו אותו כך:

- רוחב `200px`, רקע `lightblue`.
- ריפוד פנימי (`padding`) של `20px`.
- מסגרת של `5px`, קו רציף, בצבע `navy`.
- שוליים חיצוניים (`margin`) של `30px`.

עכשיו פתחו את **כלי המפתחים** (F12), בחרו את ה-`div` וענו (בהערה בקובץ ה-CSS):

1. מה הרוחב **הכולל** שהקופסה תופסת על המסך, כולל padding ו-border (בלי margin)? הסבירו את החישוב.
2. מה קורה ל-`padding` כשמשנים את הרקע לצבע אחר – גם הוא נצבע? ומה עם ה-`margin`?

## תרגיל 5 ⭐⭐ – הכרטיס שלכם

קחו את כרטיס הביקור **שלכם** משיעור 1 (תרגיל 5) ועצבו אותו עם `style.css`. דרישות חובה:

1. רקע לדף, וכרטיס לבן **ממורכז** עם `max-width`, `padding`, פינות מעוגלות וצל.
2. תמונה **עגולה** עם מסגרת.
3. גופן אחר מברירת המחדל, ולפחות שלושה צבעים שונים.
4. הכישורים/תחביבים **בשורה אחת** (Flexbox) כ"גלולות".
5. לפחות אפקט `:hover` אחד.

**אל תעתיקו את הצבעים מהחומר** – בחרו צבעים משלכם (נסו את בוחר הצבעים של VS Code, או אתר כמו `https://coolors.co`).

💾 **שמרו!** בשיעור 3 נוסיף לכרטיס JavaScript.

## תרגיל 6 ⭐⭐⭐ – תפריט ניווט

בנו בראש דף פס ניווט, כמו באתרים אמיתיים:

```html
<div class="navbar">
  <a href="#">Home</a>
  <a href="#">Courses</a>
  <a href="#">About</a>
  <a href="#">Contact</a>
</div>
```

(`href="#"` = קישור "ריק" שלא מוביל לשום מקום – שימושי לתרגול.)

1. הפס ברוחב מלא, רקע כהה (`#1e293b`), ו-`padding` של `15px`.
2. הקישורים **בשורה**, עם רווח של `20px` ביניהם, וממורכזים.
3. הקישורים לבנים, **בלי קו תחתון** (רמז: `text-decoration: none;`), ובגודל `18px`.
4. כשעומדים על קישור – הצבע שלו משתנה לכתום.
5. **בונוס:** כשעומדים על קישור, יופיע מאחוריו רקע בהיר עם פינות מעוגלות (רמז: `padding` לקישור עצמו).
