## תרגיל 2 ⭐ – מה יודפס?

**בלי להריץ** – כתבו בהערה מה יודפס בכל שורה. **אחר כך** הריצו ובדקו. על כל טעות – הסבירו במשפט מה לא הבנתם.

```js
let score = 10;
console.log(score);
score = score + 5;
console.log(score);
console.log("score");
console.log("7" + "3");
console.log(7 + 3);
console.log("Score: " + score);

function double(number) {
  console.log(number * 2);
}

double(4);
double(score);
```

## תרגיל 3 ⭐ – מצאו את הבאגים

בקוד הבא יש **חמש** טעויות, ולכן הכפתור לא עובד. מצאו ותקנו את כולן, והוסיפו הערה מעל כל תיקון.

**HTML:**

```html
<button id="hello-btn">Say hello</button>
<p id="message"></p>
<script src="script.js"></script>
```

**`script.js`:**

```js
const button = document.getElementByID("hello-btn");
const message = document.getElementById("msg");

function sayHello() {
  message.textContent = "Hello there!";

button.addEventListener("click", sayHello());

const clicks = 0;
clicks = clicks + 1;
```

(רמז: הטעות האחרונה לא תפריע לכפתור – אבל היא כן תופיע בקונסול.)

## תרגיל 4 ⭐⭐ – מונה עם שלושה כפתורים

בנו דף עם מספר גדול באמצע (מתחיל ב-`0`) ושלושה כפתורים:

- `+1` – מעלה את המספר באחד.
- `-1` – מוריד את המספר באחד.
- `Reset` – מחזיר ל-`0`.

**שדרוגים (לבחור לפחות אחד):**

1. המספר לא יורד מתחת ל-`0`. (רמז: `if` בתוך הפונקציה של `-1`.)
2. כשהמספר מגיע ל-`10` ומעלה – הוא נצבע באדום. (רמז: `element.style.color = "red";` – ואל תשכחו להחזיר לשחור כשהוא יורד!)

## תרגיל 5 ⭐⭐ – הכרטיס שלכם עושה דברים

קחו את כרטיס הביקור **שלכם** משיעור 2, והוסיפו לו:

1. כפתור לייק עם מונה.
2. כפתור מצב כהה – **בצבעים שלכם**.
3. **חדש:** כפתור `Show phone`. מספר הטלפון (מומצא!) לא מופיע בהתחלה; לחיצה מציגה אותו בתוך פסקה, והטקסט של הכפתור משתנה ל-`Hide phone`. לחיצה נוספת מסתירה אותו שוב.

רמז לסעיף 3: אפשר להשתמש באותו טריק של מצב כהה – מחלקה `hidden` עם `display: none;` ב-CSS, ו-`classList.toggle("hidden")` על הפסקה.

## תרגיל 6 ⭐⭐⭐ – ניחוש מספר

בנו משחק פשוט:

1. בתחילת `script.js`: `const secret = 7;` (המספר הסודי).
2. בדף יש **10 כפתורים**, עם המספרים 1 עד 10, ופסקה ריקה להודעות.
3. לחיצה על כפתור בודקת את הניחוש ומציגה בפסקה:
   - `Too low!` – אם הניחוש קטן מהמספר הסודי.
   - `Too high!` – אם הניחוש גדול ממנו.
   - `You got it!` – אם צדקתם.
4. בנוסף, מונה ניסיונות: `Attempts: 3`.

רמזים:

- `if` / `else if` / `else` – אפשר לשרשר כמה תנאים:

```js
if (guess < secret) {
  // ...
} else if (guess > secret) {
  // ...
} else {
  // ...
}
```

- כדי לא לכתוב 10 פונקציות שונות, כתבו פונקציה **אחת** `checkGuess(guess)` שמקבלת את הניחוש. ואיך מחברים אותה לכפתור עם מספר מסוים? כך:

```js
document.getElementById("btn-1").addEventListener("click", function () {
  checkGuess(1);
});
```

(`function () { ... }` היא פונקציה **בלי שם**, שנכתבת ישר בתוך ה-`addEventListener`. בכל לחיצה היא מפעילה את `checkGuess` עם המספר הנכון. נלמד עליה יותר בשיעור הבא.)

**בונוס:** אחרי `You got it!` – כל הכפתורים כבר לא עובדים. (רמז: משתנה `let gameOver = false;`.)
