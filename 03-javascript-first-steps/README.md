# שיעור 3 – JavaScript: הדף מתחיל לעשות דברים

> **מה צריך לדעת לפני?** את שיעורים 1 ו-2 – HTML, CSS, ואת כרטיס הביקור המעוצב שלכם.
> **כמה זמן?** שיעור אחד (כשעתיים), כולל תרגול בכיתה.
> **מה בונים?** מוסיפים לכרטיס שני כפתורים שבאמת **עובדים**: כפתור "לייק" שסופר לחיצות, וכפתור שמדליק ומכבה **מצב כהה**.

## 🎯 מה נדע בסוף השיעור

1. מה זה תכנות, ומה JavaScript עושה בדף.
2. לחבר קובץ JavaScript לדף, ולהשתמש ב**קונסול** (Console) של הדפדפן.
3. לשמור מידע ב**משתנים** (`let` ו-`const`).
4. לעבוד עם מספרים וטקסט.
5. לקבל החלטות בקוד עם `if` / `else`.
6. לכתוב **פונקציות** – ולהפעיל אותן.
7. למצוא תגית בדף, לשנות אותה, ולהגיב ל**לחיצה** על כפתור.

> 💬 **מילה לפני שמתחילים:** זה השיעור הראשון שבו **מתכנתים** באמת. HTML ו-CSS מתארים איך הדף נראה; JavaScript נותנת **הוראות**. בהתחלה זה מרגיש קשה יותר – וזה לגמרי נורמלי. כל מתכנת בעולם התחיל בדיוק כאן, עם אותן טעויות. עבדו לאט, הקלידו כל דוגמה, והסתכלו על התוצאה.

## 1. מה זה תכנות?

### 📖 הסבר

**תכנות** = לכתוב למחשב **רשימת הוראות**, שהוא מבצע **אחת אחרי השנייה, לפי הסדר**.

המחשב מהיר מאוד – אבל הוא לא חכם. הוא עושה **בדיוק** מה שכתבתם, לא מה שהתכוונתם. שגיאת כתיב קטנה – והוא לא יבין.

### 🌍 מהעולם האמיתי

תחשבו על **רובוט שמכין כריך**. אם תגידו לו "תכין כריך" – הוא לא יבין. צריך לפרק:

1. קח שתי פרוסות לחם.
2. מרח שוקולד על פרוסה אחת.
3. שים את הפרוסה השנייה מעליה.

ואם תחליפו את הסדר בין שלב 2 לשלב 3 – תקבלו כריך עם שוקולד **מבחוץ**. כך בדיוק עובד קוד: **הסדר חשוב**.

## 2. הקובץ הראשון והקונסול

### 🔨 עושים יחד – מחברים JavaScript לדף

1. פתחו ב-VS Code את התיקייה `my-card` (עם הכרטיס המעוצב משיעור 2).
2. צרו קובץ חדש בשם `script.js`.
3. כתבו בו:

```js
console.log("Hello from JavaScript!");
```

4. ב-`index.html`, **ממש לפני** `</body>` (בסוף הגוף), הוסיפו:

```html
<script src="script.js"></script>
```

> ⚠️ **למה דווקא בסוף?** הדפדפן קורא את ה-HTML מלמעלה למטה. אם הסקריפט יהיה למעלה – הוא ירוץ **לפני** שהכפתורים קיימים בדף, ולא ימצא אותם. בסוף ה-`body` – כל הדף כבר מוכן.

> ⚠️ לתגית `<script>` **חייבת** להיות תגית סגירה `</script>`, גם כשאין בה כלום.

5. שמרו את שני הקבצים, רעננו את הדפדפן... ו**שום דבר לא קרה?** 🤔

### 📖 הקונסול – "החלון האחורי" של הדפדפן

`console.log(...)` לא כותבת בדף – היא כותבת ב**קונסול**, חלון מיוחד למפתחים:

1. לחצו **F12** (או לחיצה ימנית ← **Inspect**).
2. עברו ללשונית **Console**.
3. הנה ההודעה: `Hello from JavaScript!` 🎉

הקונסול הוא החבר הכי טוב של מתכנת. שני דברים חשובים עליו:

- **`console.log(...)`** – "הדפס לי את זה". משתמשים בזה כל הזמן כדי לבדוק מה קורה בקוד.
- **שגיאות** מופיעות בו **באדום**, יחד עם שם הקובץ ומספר השורה. כשמשהו לא עובד – **הדבר הראשון** שעושים הוא לפתוח את הקונסול.

### ✋ תורכם

1. הוסיפו עוד שורת `console.log` עם השם שלכם. שמרו, רעננו, ובדקו בקונסול.
2. בקונסול עצמו (בשורה התחתונה, ליד הסימן `>`) הקלידו `2 + 3` ולחצו Enter. אפשר להשתמש בקונסול כמחשבון!

## 3. מספרים וטקסט

### 📖 הסבר

ב-JavaScript יש כמה סוגי ערכים. היום נכיר שלושה:

| סוג | דוגמה | הסבר |
|---|---|---|
| **מספר** (number) | `16`, `3.5`, `-2` | כותבים בלי מירכאות. אפשר לחשב איתם |
| **מחרוזת** (string) – טקסט | `"Dana"`, `"Hello world"` | תמיד בתוך **מירכאות** |
| **בוליאני** (boolean) – כן/לא | `true`, `false` | נפגוש אותו ב-`if` |

חשבון עובד כמו במחשבון:

```js
console.log(10 + 5);   // 15
console.log(10 - 5);   // 5
console.log(10 * 5);   // 50  (* = כפול)
console.log(10 / 5);   // 2   (/ = חלקי)
```

> 💡 `//` ב-JavaScript = **הערה**. כל מה שאחריו באותה שורה – המחשב מתעלם ממנו. כאן השתמשנו בהערות כדי לכתוב מה יודפס.

ו-`+` בין שתי מחרוזות **מחבר** אותן:

```js
console.log("Hello " + "Dana");   // Hello Dana
```

### ⚠️ המלכודת הגדולה

```js
console.log(5 + 5);       // 10
console.log("5" + "5");   // 55   (!)
```

`"5"` עם מירכאות הוא **טקסט**, לא מספר. ו-`+` בין טקסטים = **הדבקה**. כמו להדביק שני פתקים שעל כל אחד כתוב "5".

## 4. משתנים – קופסאות עם שם

### 📖 הסבר

**משתנה** (Variable) הוא **קופסה עם תווית**, שבתוכה שומרים ערך – כדי להשתמש בו אחר כך.

```js
let likes = 0;
```

| החלק | מה זה |
|---|---|
| `let` | "צור קופסה חדשה" |
| `likes` | **השם** של הקופסה (התווית) |
| `=` | "שים בתוכה" – **לא** "שווה" כמו במתמטיקה! |
| `0` | הערך שנכנס לקופסה |
| `;` | סוף ההוראה |

עכשיו אפשר להשתמש בשם במקום בערך:

```js
let likes = 0;
console.log(likes);   // 0

likes = likes + 1;
console.log(likes);   // 1
```

השורה `likes = likes + 1;` נראית מוזרה במתמטיקה – אבל בתכנות היא אומרת: "קח את מה שיש עכשיו בקופסה (`0`), הוסף 1, ושים את התוצאה **בחזרה** בקופסה". עכשיו יש בה `1`.

### 📖 `let` או `const`?

| המילה | מתי | אפשר לשנות אחר כך? |
|---|---|---|
| `let` | ערך שישתנה – מונה, ניקוד במשחק | ✅ כן |
| `const` | ערך שלא ישתנה – שם, תאריך לידה | ❌ לא (מ-constant – קבוע) |

```js
const firstName = "Dana";
firstName = "Rana";   // ❌ Error: Assignment to constant variable.
```

> 💡 **כלל אצבע:** תמיד התחילו עם `const`. אם צריך לשנות את הערך – החליפו ל-`let`.

### 📖 חוקים לשמות של משתנים

- באנגלית, בלי רווחים. שתי מילים או יותר – **המילה השנייה מתחילה באות גדולה**: `firstName`, `likeCount`. (זה נקרא camelCase – "גבנון של גמל" 🐫.)
- שמות **ברורים**: `likes` ולא `x`. בעוד שבוע לא תזכרו מה זה `x`.
- **אותיות גדולות וקטנות חשובות!** `likes` ו-`Likes` הם שני משתנים שונים.

### ✋ תורכם

ב-`script.js` (מחקו את מה שהיה בו) כתבו:

1. `const` עם השם שלכם, ו-`const` עם שנת הלידה שלכם.
2. `const age = 2026 - birthYear;` (עם השם שנתתם למשתנה של שנת הלידה).
3. הדפיסו: `console.log("My name is " + myName + " and I am " + age);`

שימו לב לרווחים **בתוך** המירכאות – בלעדיהם המילים יידבקו.

## 5. החלטות: `if` / `else`

### 📖 הסבר

לפעמים הקוד צריך **להחליט**: אם משהו נכון – עשה דבר אחד, ואם לא – דבר אחר.

```js
const age = 17;

if (age >= 18) {
  console.log("You can get a driving license");
} else {
  console.log("Wait a little more");
}
```

| החלק | מה זה |
|---|---|
| `if` | "אם…" |
| `(age >= 18)` | **התנאי** – שאלה שהתשובה עליה היא `true` (כן) או `false` (לא) |
| `{ ... }` הראשון | מה עושים אם **כן** |
| `else { ... }` | "אחרת" – מה עושים אם **לא**. (לא חובה) |

**סימני השוואה:**

| הסימן | המשמעות | דוגמה שהתשובה עליה `true` |
|---|---|---|
| `===` | שווה ל- | `5 === 5` |
| `!==` | לא שווה ל- | `5 !== 3` |
| `>` / `<` | גדול מ- / קטן מ- | `10 > 3` |
| `>=` / `<=` | גדול או שווה / קטן או שווה | `18 >= 18` |

> ⚠️ **`=` מול `===`:** סימן `=` אחד = "שים בקופסה". שלושה `===` = "האם שווה?". בתוך `if` – כמעט תמיד `===`.

### 🌍 מהעולם האמיתי

**שומר בכניסה למסיבה:** "**אם** הגיל גדול או שווה ל-18 – תיכנס. **אחרת** – הביתה."

### ✋ תורכם

כתבו משתנה `grade` (ציון) ו-`if`/`else` שמדפיס `Passed` אם הציון 56 ומעלה, ו-`Failed` אחרת. שנו את הציון כמה פעמים ובדקו ששני המקרים עובדים.

## 6. פונקציות – מתכון עם שם

### 📖 הסבר

**פונקציה** (Function) היא **קבוצת הוראות עם שם**. כותבים אותה **פעם אחת**, ומפעילים אותה **מתי שרוצים, כמה פעמים שרוצים**.

```js
// Define the function (write the recipe)
function sayHello() {
  console.log("Hello!");
  console.log("Welcome to my site");
}

// Call the function (cook it!)
sayHello();
sayHello();
```

| השלב | הקוד | מה קורה |
|---|---|---|
| **הגדרה** | `function sayHello() { ... }` | כותבים את המתכון. **שום דבר עוד לא קורה!** |
| **הפעלה** (קריאה) | `sayHello();` | עכשיו ההוראות שבתוך `{ }` רצות |

בדוגמה, "Hello!" ו-"Welcome to my site" יודפסו **פעמיים** – כי הפעלנו את הפונקציה פעמיים.

### 🌍 מהעולם האמיתי

**מתכון לעוגה** כתוב בספר. כל עוד אף אחד לא מכין אותו – אין עוגה. ההגדרה = לכתוב את המתכון. ההפעלה = להכין עוגה לפיו. ואפשר להכין אותה שוב ושוב, בלי לכתוב את המתכון מחדש.

> ⚠️ **הסוגריים `()` הם ההבדל!** `sayHello` (בלי סוגריים) = **שם** המתכון. `sayHello()` (עם סוגריים) = "**תכין** את זה עכשיו".

### 📖 פונקציה שמקבלת מידע

אפשר לתת לפונקציה "חומרי גלם" – בתוך הסוגריים:

```js
function greet(name) {
  console.log("Hello " + name + "!");
}

greet("Dana");    // Hello Dana!
greet("Omar");    // Hello Omar!
```

`name` הוא משתנה שמקבל את הערך ששלחנו בכל הפעלה.

### ✋ תורכם

כתבו פונקציה בשם `showAge` שמקבלת שנת לידה (`birthYear`) ומדפיסה את הגיל ב-2026. הפעילו אותה שלוש פעמים, עם שלוש שנים שונות.

## 7. JavaScript פוגשת את הדף

### 📖 הסבר

עד עכשיו כתבנו רק בקונסול. עכשיו החלק המרגש: JavaScript יכולה **למצוא כל תגית בדף ולשנות אותה**.

כדי למצוא תגית, נותנים לה ב-HTML **מזהה** – `id` – שם ייחודי שמופיע **רק פעם אחת** בכל הדף:

```html
<span id="like-count">0</span>
```

וב-JavaScript מוצאים אותה לפי המזהה:

```js
const likeCount = document.getElementById("like-count");
```

| החלק | מה זה |
|---|---|
| `document` | **הדף כולו** |
| `.getElementById(...)` | "מצא את התגית שה-`id` שלה הוא…" |
| `"like-count"` | ה-`id` – **בדיוק** כמו ב-HTML |
| `const likeCount =` | שומרים את התגית שמצאנו בקופסה, כדי להשתמש בה אחר כך |

עכשיו אפשר **לשנות את הטקסט** שלה:

```js
likeCount.textContent = 5;
```

`textContent` = "הטקסט שבתוך התגית". שמרו ורעננו – במקום `0` יופיע `5`!

> 💡 **`class` מול `id`:** `class` – לעיצוב ב-CSS, ויכול להופיע על כמה תגיות. `id` – כדי ש-JavaScript תמצא תגית **אחת** מסוימת.

> ⚠️ שימו לב לאותיות: `getElementById` – ה-**B** גדולה, וה-**d** בסוף קטנה. `getElementByID` לא יעבוד!

## 8. אירועים – "כשלוחצים על הכפתור…"

### 📖 הסבר

**אירוע** (Event) = משהו שהמשתמש עשה: לחץ, הקליד, גלל. אפשר להגיד לתגית: "**כשקורה לך אירוע מסוים – הפעילי את הפונקציה הזאת**":

```js
likeButton.addEventListener("click", addLike);
```

| החלק | מה זה |
|---|---|
| `likeButton` | הכפתור (שמצאנו קודם עם `getElementById`) |
| `.addEventListener(...)` | "הקשב ל…" |
| `"click"` | סוג האירוע – לחיצה |
| `addLike` | **שם** הפונקציה שתופעל בכל לחיצה – **בלי סוגריים!** |

> ⚠️ **למה בלי סוגריים?** `addLike()` עם סוגריים = "הפעל **עכשיו**, מיד". אבל אנחנו לא רוצים עכשיו – אנחנו **מוסרים לכפתור את המתכון**, והוא יכין אותו בכל פעם שילחצו עליו.

### 🌍 מהעולם האמיתי

**פעמון בדלת:** מחברים את הכפתור לפעמון פעם אחת (`addEventListener`). מאותו רגע – בכל פעם שמישהו לוחץ, הפעמון מצלצל (הפונקציה רצה).

## 9. 🔨 בונים יחד – כפתור "לייק"

### שלב 1 – ה-HTML

בתוך ה-`div` של הכרטיס, אחרי החלק של `Contact me`, הוסיפו:

```html
<p>
  <button id="like-btn">Like</button>
  <span id="like-count">0</span> likes
</p>
```

- `<button>` – תגית חדשה: **כפתור**.
- `<span>` – כמו `div`, קופסה ריקה – אבל **בתוך השורה** (לא יורדת שורה). נוח כשרוצים לשנות רק מילה אחת או מספר אחד.

### שלב 2 – ה-JavaScript

מחקו את כל מה שב-`script.js` והקלידו:

```js
// 1. Find the elements on the page
const likeButton = document.getElementById("like-btn");
const likeCount = document.getElementById("like-count");

// 2. The data
let likes = 0;

// 3. What happens when someone clicks "Like"
function addLike() {
  likes = likes + 1;
  likeCount.textContent = likes;
}

// 4. Connect the button to the function
likeButton.addEventListener("click", addLike);
```

שמרו, רעננו – ולחצו על הכפתור כמה פעמים. המספר עולה! 🎉

### 📖 מה בדיוק קורה? בואו נעקוב

1. **כשהדף נטען:** הקוד רץ מלמעלה למטה – מוצא את הכפתור ואת ה-`span`, יוצר קופסה `likes` עם `0`, **מגדיר** את `addLike` (עוד לא מפעיל!), ומחבר אותה לכפתור. זהו – הקוד "מחכה".
2. **לחיצה ראשונה:** הכפתור מפעיל את `addLike`. בתוכה: `likes` הופך מ-`0` ל-`1`, ואז הטקסט ב-`span` משתנה ל-`1`.
3. **לחיצה שנייה:** שוב `addLike` – `likes` הופך ל-`2`, והמסך מציג `2`. וכן הלאה.

### שלב 3 – הפתעה ב-10 לייקים

עכשיו נשלב את `if`. בתוך `addLike`, **אחרי** השורה של `textContent`, הוסיפו:

```js
  if (likes === 10) {
    alert("Wow! 10 likes!");
  }
```

`alert(...)` מציגה חלון הודעה קופץ. לחצו 10 פעמים ובדקו!

### ✋ תורכם

1. מה יקרה אם תמחקו את השורה `likeCount.textContent = likes;`? נסו, ובדקו בעזרת `console.log(likes);` בתוך הפונקציה מה קורה **לקופסה**. (את התשובה נצטט שוב בסוף השיעור – היא חשובה!)
2. הוסיפו כפתור שני, `Reset`, שמחזיר את המונה ל-`0`. (רמז: `id` חדש, פונקציה חדשה `resetLikes`, ו-`addEventListener` חדש.)

## 10. 🔨 בונים יחד – מצב כהה

### 📖 הרעיון

לא נשנה כל צבע בנפרד ב-JavaScript. במקום זה, ניתן ל-`body` **מחלקה** בשם `dark` – וה-CSS כבר יידע מה לעשות. JavaScript רק "מדליקה ומכבה" את המחלקה.

### שלב 1 – ה-CSS

הוסיפו בסוף `style.css`:

```css
/* Buttons */
button {
  background-color: #1e3a8a;
  color: white;
  border: none;
  padding: 10px 20px;
  border-radius: 8px;
  font-size: 16px;
  cursor: pointer;
}

button:hover {
  background-color: #2563eb;
}

/* Dark mode - used only when body has the class "dark" */
.dark {
  background-color: #0f172a;
}

.dark .card {
  background-color: #1e293b;
  color: #e2e8f0;
}

.dark h1 {
  color: #93c5fd;
}
```

`cursor: pointer;` – העכבר הופך ל"יד" מעל הכפתור, כמו מעל קישור. `.dark .card` = "כרטיס שנמצא **בתוך** משהו עם המחלקה `dark`".

### שלב 2 – ה-HTML

מתחת ל-`<p>` של הלייקים, עדיין בתוך הכרטיס:

```html
<button id="theme-btn">Dark mode</button>
```

### שלב 3 – ה-JavaScript

הוסיפו ל-`script.js` (שימו לב לסדר – המציאה בהתחלה, החיבור בסוף):

```js
const themeButton = document.getElementById("theme-btn");

function toggleTheme() {
  document.body.classList.toggle("dark");

  if (document.body.classList.contains("dark")) {
    themeButton.textContent = "Light mode";
  } else {
    themeButton.textContent = "Dark mode";
  }
}

themeButton.addEventListener("click", toggleTheme);
```

| הקוד | מה הוא עושה |
|---|---|
| `document.body` | התגית `<body>` (לה לא צריך `id` – יש לה קיצור דרך) |
| `.classList.toggle("dark")` | **מתג**: אם אין מחלקה `dark` – מוסיף. אם יש – מוריד |
| `.classList.contains("dark")` | שאלה: "יש עכשיו מחלקה `dark`?" – `true` או `false` |

ה-`if` משנה את הטקסט של הכפתור, כדי שתמיד יגיד מה **יקרה** בלחיצה הבאה.

### ✋ תורכם

לחצו על הכפתור, ובכלי המפתחים, בלשונית **Elements**, הסתכלו על התגית `<body>`. מה מופיע ונעלם בכל לחיצה?

## 11. 💻 הקוד המלא

הקוד נמצא גם בתיקייה [`project`](project/) של השיעור. (`style.css` הוא זה של שיעור 2, ובסופו התוספות מסעיף 10.)

**`index.html`:**

```html
<!DOCTYPE html>
<html lang="en">
  <head>
    <meta charset="UTF-8">
    <title>Dana Cohen - Business Card</title>
    <link rel="stylesheet" href="style.css">
  </head>
  <body>
    <!-- The business card -->
    <div class="card">
      <img class="avatar" src="avatar.svg" alt="Photo of Dana Cohen">
      <h1>Dana Cohen</h1>
      <h2 class="role">Web Developer</h2>
      <p>I live in <strong>Yarka</strong> and I love building websites.</p>

      <h3>My skills</h3>
      <ul class="skills">
        <li>HTML</li>
        <li>CSS</li>
        <li>JavaScript</li>
      </ul>

      <h3>Contact me</h3>
      <p>Email: <a href="mailto:dana@example.com">dana@example.com</a></p>
      <p>Website: <a href="https://react.dev" target="_blank">My favorite site</a></p>

      <!-- New in lesson 3: buttons that DO something -->
      <p>
        <button id="like-btn">Like</button>
        <span id="like-count">0</span> likes
      </p>
      <button id="theme-btn">Dark mode</button>
    </div>

    <!-- JavaScript - always at the end of body -->
    <script src="script.js"></script>
  </body>
</html>
```

**`script.js`:**

```js
// 1. Find the elements on the page
const likeButton = document.getElementById("like-btn");
const likeCount = document.getElementById("like-count");
const themeButton = document.getElementById("theme-btn");

// 2. The data
let likes = 0;

// 3. What happens when someone clicks "Like"
function addLike() {
  likes = likes + 1;
  likeCount.textContent = likes;

  if (likes === 10) {
    alert("Wow! 10 likes!");
  }
}

// 4. Dark mode on / off
function toggleTheme() {
  document.body.classList.toggle("dark");

  if (document.body.classList.contains("dark")) {
    themeButton.textContent = "Light mode";
  } else {
    themeButton.textContent = "Dark mode";
  }
}

// 5. Connect each button to its function
likeButton.addEventListener("click", addLike);
themeButton.addEventListener("click", toggleTheme);
```

> 💡 **שימו לב למבנה – הוא יחזור בכל קובץ JavaScript שתכתבו:** (1) מוצאים את התגיות, (2) מגדירים את הנתונים, (3) כותבים פונקציות, (4) מחברים אירועים לפונקציות.

## 12. 🔎 איך קוראים שגיאה אדומה בקונסול

כשמשהו לא עובד – **אל תיבהלו מהאדום**. השגיאה היא רמז שהמחשב נותן לכם. לדוגמה:

```text
Uncaught TypeError: Cannot read properties of null (reading 'addEventListener')
    at script.js:31
```

- **`script.js:31`** – הבעיה ב**שורה 31** בקובץ `script.js` (בקוד המלא שלמעלה זו השורה `likeButton.addEventListener(...)`). לחצו על זה – והדפדפן יראה לכם את השורה.
- **`null`** – פירושו "כלום, לא נמצא". כלומר: `getElementById` **לא מצאה** את התגית, ולכן אין למה לחבר אירוע.
- **הסיבה כמעט תמיד:** ה-`id` ב-JavaScript שונה מה-`id` ב-HTML (למשל `like-button` מול `like-btn`), או שתגית ה-`<script>` לא נמצאת בסוף ה-`body`.

## 13. ⚠️ טעויות נפוצות – ואיך מתקנים

| מה קרה | למה | התיקון |
|---|---|---|
| שום דבר לא קורה, ואין שגיאה | הקובץ לא מחובר: שם שגוי ב-`src`, או חסר `</script>` | בדקו את שורת ה-`<script>` |
| `Cannot read properties of null` | ה-`id` לא תואם, או ש-`<script>` לא בסוף ה-`body` | השוו את ה-`id` אות-אות |
| `getElementByID is not a function` | אותיות גדולות/קטנות | `getElementById` |
| `likes is not defined` | שגיאת כתיב בשם המשתנה, או שימוש לפני ההגדרה | השם זהה בכל מקום, וההגדרה למעלה |
| הפונקציה רצה פעם אחת כשהדף נטען, ולא בלחיצה | `addEventListener("click", addLike())` – עם סוגריים | `addLike` – **בלי** סוגריים |
| `Assignment to constant variable` | ניסיתם לשנות משתנה `const` | החליפו ל-`let` |
| `"5" + "5"` יצא `55` | אלה מחרוזות (מירכאות), לא מספרים | כתבו מספרים בלי מירכאות |
| `if (likes = 10)` מתנהג מוזר | `=` אחד הוא "שים", לא "האם שווה" | `===` |
| `Unexpected end of input` | חסר `}` – לא סגרתם פונקציה או `if` | ספרו: לכל `{` יש `}`. (Shift + Alt + F עוזר לראות) |

## 14. 🤔 ולמה כל זה קשור ל-React ול-Angular?

זוכרים את התרגיל שבו מחקתם את `likeCount.textContent = likes;`? הקופסה `likes` **עלתה**, אבל המסך **לא השתנה**. ב-JavaScript רגילה, **אתם** אחראים לעדכן את המסך בכל פעם שהנתונים משתנים.

עכשיו דמיינו את פייסבוק: מספר הלייקים מופיע מתחת לפוסט, בהתראות, בפרופיל… ואם שוכחים לעדכן מקום אחד – המשתמש רואה מספרים סותרים.

**זו בדיוק הבעיה ש-React ו-Angular פותרות:** משנים רק את **הנתונים** (`likes`), והמסך מתעדכן **לבד**, בכל המקומות. אבל כדי להבין את הקסם הזה – הייתם חייבים קודם לראות איך עושים את זה "ביד". ועכשיו ראיתם. 💪

## ✅ בדקו את עצמכם

1. מה ההבדל בין `let` ל-`const`? מתי תשתמשו בכל אחד?
2. מה יודפס: `console.log("10" + "5");`? ומה יודפס: `console.log(10 + 5);`? למה?
3. מה ההבדל בין `=` ל-`===`?
4. כתבתם פונקציה `function hello() { ... }` – אבל שום דבר לא קורה. מה שכחתם?
5. למה כותבים `addEventListener("click", addLike)` **בלי** סוגריים אחרי `addLike`?
6. בקונסול מופיעה השגיאה `Cannot read properties of null`. מה שתי הסיבות הנפוצות?
7. למה את תגית ה-`<script>` שמים בסוף ה-`body`?
8. בכפתור הלייק – מה התפקיד של השורה `likeCount.textContent = likes;`, ומה קורה בלעדיה?

<details><summary>תשובות</summary>

1. `let` – אפשר לשנות את הערך אחר כך (מונה, ניקוד). `const` – אי אפשר (שם, תאריך לידה). מתחילים תמיד ב-`const`, ועוברים ל-`let` רק אם צריך לשנות.
2. `105` – כי אלה מחרוזות, ו-`+` מדביק אותן. ו-`15` – כי אלה מספרים, ו-`+` מחבר.
3. `=` – "שים ערך בתוך משתנה". `===` – "האם שני הערכים שווים?" (משתמשים בו בתנאים).
4. להפעיל אותה: `hello();`. הגדרה לבד לא מריצה כלום.
5. כי אנחנו לא רוצים להפעיל את הפונקציה **עכשיו** – אנחנו מוסרים אותה לכפתור, והוא יפעיל אותה בכל לחיצה. עם סוגריים היא הייתה רצה פעם אחת מיד בטעינת הדף.
6. ה-`id` ב-JavaScript לא זהה ל-`id` ב-HTML, או ש-`<script>` נמצא לפני התגית (למשל ב-`head`), ולכן היא עוד לא קיימת כשהקוד רץ.
7. כי הדפדפן קורא את הדף מלמעלה למטה. בסוף ה-`body` כל התגיות כבר קיימות, ו-JavaScript יכולה למצוא אותן.
8. היא מעדכנת את **המסך** לפי הערך החדש במשתנה. בלעדיה – המשתנה גדל, אבל המסך ממשיך להציג `0`.

</details>
