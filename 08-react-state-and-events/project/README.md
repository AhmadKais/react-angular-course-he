# איך מריצים את הפרויקט

הפרויקט נשמר **בלי** התיקייה `node_modules` (היא ענקית). כדי להריץ אותו:

1. פתחו את התיקייה `project` ב-VS Code (**File ← Open Folder**).
2. פתחו טרמינל (**Terminal ← New Terminal**) והריצו:

```bash
npm install
npm run dev
```

3. פתחו בדפדפן את הכתובת שמופיעה בטרמינל – בדרך כלל `http://localhost:5173/`.
4. כדי לעצור את השרת – לחצו בטרמינל **Ctrl + C**.
