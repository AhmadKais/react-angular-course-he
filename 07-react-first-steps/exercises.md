## תרגיל 2 ⭐ – מצאו את הבאגים

בקוד הבא יש **שש** טעויות. מצאו ותקנו את כולן, והוסיפו מעל כל תיקון הערה (`{/* ... */}` בתוך JSX, או `//` מחוץ לו) שמסבירה מה היה לא בסדר.

```jsx
function profile() {
  const name = "Omar";
  const age = 16;

  return (
    <h1 class="title">Hello name</h1>
    <img src="/avatar.svg">
    <p>Next year: {age + 1}</p>
  );
}

export default profile;
```

## תרגיל 3 ⭐⭐ – "קצת עליי" מחושב

כתבו `App` שבתחילתו המשתנים הבאים (עם ערכים שלכם):

```jsx
const firstName = "...";
const lastName = "...";
const birthYear = 2009;
const favoriteFoods = ["...", "...", "..."];
```

הרכיב יציג:

1. את השם המלא – **באותיות גדולות** (רמז: `toUpperCase()`).
2. את הגיל ב-2026 – **מחושב** מ-`birthYear`, לא כתוב ביד.
3. את המשפט: `I have 3 favorite foods. The first one is ...` – גם המספר וגם המאכל מחושבים מהמערך.
4. את כל המאכלים ברשימה (`ul`) – עם `map` ו-`key`.

## תרגיל 4 ⭐⭐ – רכיב עם Props

1. צרו רכיב `Product` בקובץ משלו, שמקבל שלושה Props: `name`, `price` ו-`emoji`, ומציג:

```text
🍕 Pizza
45 ₪
```

2. ב-`App`, הציגו **שלושה** מוצרים שונים – כתובים ביד: `<Product ... />` שלוש פעמים.
3. הוסיפו Prop רביעי: `onSale` (`true` / `false`). אם המוצר במבצע – הציגו מתחת למחיר `On sale!`. (רמז: אופרטור טרנרי בתוך `{ }`, שמחזיר טקסט או `""`.)

**שאלה למחשבה:** למה `price={45}` ולא `price="45"`? מה היה קורה אם הייתם רוצים להציג גם את המחיר אחרי 10% הנחה?
